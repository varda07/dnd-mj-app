# Sons du lanceur de dés

Dépose ici trois fichiers MP3 (libres de droits) :

- `dice-roll.mp3` — joué quand l'utilisateur clique « Lancer »
- `crit-success.mp3` — joué sur un 20 naturel (d20)
- `crit-fail.mp3` — joué sur un 1 naturel (d20)

Sources gratuites suggérées : freesound.org, mixkit.co, pixabay.com/sound-effects.

L'utilisateur peut aussi surcharger chaque URL depuis l'onglet « Paramètres »
du lanceur de dés (les URLs personnalisées sont stockées en `localStorage`).
